# Презентация сайта-портфолио для соцсетей

Материалы для публикации **самого сайта-портфолио** (не отдельных проектов) на Behance, Dribbble и в соцсетях. Все изображения сняты с реального сайта в браузере.

## Что внутри
```
behance/   обложка 808×632 + 11 изображений для страницы проекта (ширина 1400 px)
dribbble/  5 шотов 1600×1200 (4:3)
social/    превью ссылки 1200×630, квадрат 1080×1080, портрет 1080×1350, сторис 1080×1920,
           баннер LinkedIn 1584×396, широкий кадр 1920×1080
тексты:    behance-description.md, dribbble-description.md, social-posts.md
```

## Порядок загрузки на Behance
1. Новый проект → загрузите обложку `00-cover-808x632.jpg`.
2. Добавьте изображения по порядку номеров `01`…`11`.
3. Вставьте описание, теги и инструменты из `behance-description.md`; вместо `<ССЫЛКА НА САЙТ>` подставьте адрес сайта после публикации.

## Dribbble
Первым шотом публикуйте `shot-1-hero`. Подпись и теги в `dribbble-description.md`.

## Соцсети
| Файл | Куда |

| `square-1080x1080.jpg`, `portrait-1080x1350.jpg` | пост в Instagram, Threads, VK |

Готовые подписи на русском и английском: `social-posts.md`.

## Что проверить перед публикацией
1. **Адрес сайта.** Сначала опубликуйте сайт (GitHub Pages или Netlify), затем подставьте ссылку в тексты.
2. **Персонаж в hero.** Анимация и персонаж взяты из присланных вами материалов. Если они созданы нейросетью, Behance и Dribbble просят отметить это (на Behance есть отметка про AI-инструменты).
3. **Тексты проектов** на сайте помечены как концепты или прототипы. Не называйте их коммерческими работами, пока это не так.
4. **FlowAutomate**: исходный Framer-проект оказался копией стороннего шаблона. Решите, как подавать этот кейс.

## Чего нет
* **Видео-прокрутки сайта.** Я пробовал записать его в браузере без видеокарты: получилось около 11 кадров в секунду, то есть рывками. Для презентации лучше записать экран на своём компьютере (QuickTime или OBS), 1920×1080, 30–60 fps, медленная прокрутка от hero до контактов, 20–30 секунд.
* **Мокапов устройств** (ноутбук, телефон вокруг сайта) в этом наборе нет. На экранах только настоящие кадры сайта.
