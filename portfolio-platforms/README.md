# Файлы для Behance, Dribbble и соцсетей

Все изображения сделаны из настоящих материалов проектов (скриншоты и мокапы, которые вы присылали). Ничего не выдумано и не сгенерировано.

## Структура
```
behance/<проект>/   обложка 808×632, изображения для страницы проекта (до 1400 px по ширине), description.md с текстом
dribbble/<проект>/  3 шота 1600×1200 (4:3) и description.md
social/             превью 1200×630 для LinkedIn, Telegram, Open Graph
```
Проекты: `triply`, `lumie`, `muza`, `saas` (FlowAutomate), `gift-match`.

## Форматы площадок
| Площадка | Что | Размер | Формат |
|---|---|---|---|
| Behance | Обложка проекта | 808×632 | JPG |
| Behance | Изображения в теле проекта | ширина до 1400 px, не растягивались | PNG |
| Dribbble | Шот | 1600×1200 (4:3), минимум 800×600 | JPG/PNG |
| Соцсети | Превью ссылки | 1200×630 | JPG |

Каждый файл меньше 10 МБ. Если площадка изменит требования, размеры можно поправить.

## Порядок загрузки на Behance
1. Создайте проект, загрузите обложку `00-cover-808x632.jpg`.
2. В редакторе добавьте изображения по порядку номеров (список есть в конце каждого `description.md`).
3. Вставьте текст из `description.md`: описание, теги, инструменты. Поля «[fill in]» и «[confirm]» заполните сами.
4. Добавьте ссылку на живой сайт (после публикации на GitHub Pages) и на ваш профиль.

## Порядок на Dribbble
Первым публикуйте `shot-1-mockup`. Текст и теги берите из `dribbble/<проект>/description.md`. Для Dribbble нужен аккаунт, который уже может публиковать шоты.

## Что проверить перед публикацией
1. **FlowAutomate (saas):** Framer-проект является копией стороннего шаблона (в метаданных «Flowcore – AI automation agency framer template»), а на скриншотах бренд Flowcore. Публиковать как собственный дизайн можно только то, что вы действительно сделали. Укажите, что именно вы доработали, или не публикуйте этот проект.
2. **MUZA и TRIPLY:** фотографии и видео на них, судя по именам файлов, созданы нейросетями. Behance и Dribbble просят отмечать работы, сделанные с помощью ИИ (на Behance есть отметка про AI-инструменты). Уточните происхождение изображений.
3. **GIFT MATCH:** в галерее используются стоковые фото (слои Unsplash в Figma). Для концепта это нормально, но подпишите их как sample.
4. **Роль и инструменты:** в `description.md` отмечены «[confirm]». Не публикуйте роль, которую не можете подтвердить.
5. **Цифры и отзывы** на страницах MUZA, GIFT MATCH и LUMIÉ учебные. В описаниях я их не использовал как результаты, не добавляйте их и вы.
6. Тексты на изображениях LUMIÉ и GIFT MATCH русские, остальные проекты на английском. Для международной аудитории можно сделать английские версии.

## Чего не хватает
* **MUZA:** нет настоящих скриншотов hero, слайдера до/после и карточек проектов. Картинки на Cloudinary недоступны из песочницы. Мокап планшета используется как главный кадр. Нужны PNG 2880×1800 этих блоков.
* **GIFT MATCH:** мобильные экраны взяты из фрейма Figma шириной 320 px, поэтому они небольшие. Нужен экспорт в 3x.
* **LUMIÉ:** нет страницы `/catalog` и мобильных кадров в высоком разрешении.
* **SAAS:** нет мобильных экранов, только ширина планшета.
* **Мокапы:** шоты Dribbble `shot-1-mockup` увеличены примерно в 1,17 раза (исходники 1536×1024). Если есть оригиналы мокапов в 3200×2400, замените их.
